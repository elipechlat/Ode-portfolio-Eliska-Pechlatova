### FarMappa
**Bilingual map and database of organic farms and local food 
producers in the Czech Republic**

FarMappa is a Python-based data platform that automatically 
discovers, collects, and maps organic farms, beekeepers, 
farmers markets, community gardens, and local food producers 
across the Czech Republic. Built entirely with Claude Code.

**What it does:**
- Automated scraping agents collect producer data from multiple 
  Czech directories
- Bilingual database (Czech/English) with 1000+ locations and 
  GPS coordinates
- 18 product categories with multi-tag support per location
- Interactive map prototype with category filters built with 
  Leaflet.js and OpenStreetMap
- Modular multi-source agent framework — new data sources can 
  be added in minutes

**Tech stack:** Python, SQLite, Leaflet.js, BeautifulSoup, 
Nominatim geocoding API, Claude Code

**Status:** Active development — data collection agents 
operational, web prototype running, mobile app planned

### ESG Reporting Agent
**Two-agent Claude-powered app for qualitative ESG analysis 
of microbusiness interviews**

A dual-agent system built directly in Claude AI that automates 
the qualitative coding and analysis of ESG interview transcripts 
from microbusinesses — turning raw interview data into structured, 
analysable ESG reporting outputs.

**How it works:**
- **Agent 1 — Coder:** Takes raw interview transcripts from 
  microbusiness ESG interviews and outputs structured coded 
  data using a defined schema
- **Agent 2 — Analyst:** Takes coded outputs from multiple 
  interviews and runs full cross-interview analysis, identifying 
  patterns, gaps, and key ESG themes

**Use case:** Designed for researchers and consultants working 
with small businesses on ESG disclosure and sustainability 
reporting, where manual coding is time-intensive and 
inconsistent across analysts.

**Tech stack:** Claude AI, prompt engineering, multi-agent 
architecture

**Status:** Operational
